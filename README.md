# YouTube TV Enhanced

A Tampermonkey userscript that improves the YouTube TV web interface with higher-quality video thumbnails and seek previews.

## Features

- **High-resolution thumbnails:** Replaces low-quality video thumbnails with higher-resolution images, up to 1280×720 when available.
- **Improved seek previews:** Uses higher-resolution storyboard images when available, increasing preview resolution from 80×45 to 160×90.
- **Automatic enhancements:** Works in the background while browsing and watching videos.
- **Designed for YouTube TV:** Built for the TV-style YouTube interface running in a desktop browser.

## Requirements

- Google Chrome or a compatible browser
- Tampermonkey
- Access to the YouTube TV web interface at `youtube.com/tv`
